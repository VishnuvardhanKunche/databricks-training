# Offline Databricks Training

## Overview

This folder contains all the assignments and practice exercises completed during my **Offline Databricks Training**. The training focuses on building a strong foundation in **SQL**, **PySpark**, and **Databricks** through hands-on exercises and real-world data engineering scenarios.

Each assignment is organized day-wise and includes the questions provided during the training, the corresponding solutions, notebooks (where applicable), and documentation explaining the concepts covered. The assignments are designed to progressively enhance problem-solving skills and practical understanding of data engineering workflows.

## Topics Covered

* SQL Fundamentals
* Filtering, Sorting, and Aggregations
* Joins and Set Operations
* Subqueries
* Common Table Expressions (CTEs)
* Window Functions
* PySpark DataFrame Operations
* Data Cleaning and Transformation
* ETL Pipeline Development
* Business Analytics Scenarios
* Databricks Notebook Practice

## Learning Objectives

* Develop strong SQL problem-solving skills.
* Learn PySpark DataFrame transformations and operations.
* Understand data cleaning and preprocessing techniques.
* Build and implement ETL pipelines.
* Gain hands-on experience with Databricks notebooks.
* Apply SQL and PySpark concepts to real-world business scenarios.
* Strengthen the fundamentals required for Data Engineering roles.

## Repository Contents

Each day's assignment may include:

* Assignment questions
* SQL solution files
* PySpark notebooks
* Sample datasets
* README documentation describing the work completed
