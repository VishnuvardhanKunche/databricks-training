## Overview

Assignment 3 focused on building a strong foundation in **PySpark DataFrame operations** through a comprehensive set of 100 practice questions. The exercises covered everything from DataFrame creation to advanced transformations, joins, window functions, and business reporting.

## PySpark Functions Used

| Function                              | Purpose                  |
| ------------------------------------- | ------------------------ |
| `select()`                            | Select required columns  |
| `filter()`                            | Filter records           |
| `withColumn()`                        | Create or modify columns |
| `withColumnRenamed()`                 | Rename columns           |
| `drop()`                              | Remove columns           |
| `fillna()`                            | Replace NULL values      |
| `dropna()`                            | Remove NULL records      |
| `groupBy()`                           | Group data               |
| `agg()`                               | Aggregate data           |
| `sum()`                               | Calculate total          |
| `avg()`                               | Calculate average        |
| `count()`                             | Count records            |
| `max()`                               | Maximum value            |
| `min()`                               | Minimum value            |
| `join()`                              | Join DataFrames          |
| `union()`                             | Combine DataFrames       |
| `unionByName()`                       | Union using column names |
| `distinct()`                          | Retrieve unique values   |
| `dropDuplicates()`                    | Remove duplicate rows    |
| `orderBy()`                           | Sort records             |
| `when()`                              | Conditional expressions  |
| `upper()` / `lower()`                 | Case conversion          |
| `substring()`                         | Extract substring        |
| `concat()` / `concat_ws()`            | Concatenate strings      |
| `regexp_replace()`                    | Replace characters       |
| `to_date()`                           | Convert to DateType      |
| `year()` / `month()` / `dayofmonth()` | Date extraction          |
| `datediff()`                          | Date difference          |
| `date_add()`                          | Add days to date         |
| `current_date()`                      | Current system date      |
| `current_timestamp()`                 | Current timestamp        |
| `rank()`                              | Rank rows                |
| `row_number()`                        | Sequential numbering     |
| `Window`                              | Window specifications    |
